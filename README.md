# Kisaane AI App

An AI-powered agricultural helper web application for farmers built with React 19, Vite, TailwindCSS v4, Lucide React, and Supabase.

---

## 🚀 NPM Run Commands

| Command | Description |
| :--- | :--- |
| `npm run dev` | Launch development server with HMR at `http://localhost:5173/` |
| `npm start` | Alias for `npm run dev` |
| `npm run build` | Compile and bundle production assets into `dist/` |
| `npm run preview` | Serve the production build locally to test dist output |
| `npm run lint` | Run Oxlint linter check across source files |
| `npm run check` | Run full validation (build + lint check) |
